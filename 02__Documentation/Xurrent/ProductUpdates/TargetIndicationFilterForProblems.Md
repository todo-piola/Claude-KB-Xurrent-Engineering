# Target Indication Filter for Problems

It was already possible to [filter requests, change tasks and project tasks by target indication](https://www.xurrent.com/product-updates/two-more-report-filters).  Now problem views and reports can also be filtered by target indication.

To bring the list of target indication options more in line with other filter options, the ‘No target’ option has been renamed to ‘None’.  In addition, the list of options that people can choose from is now limited to the ones that will result in at least 1 match with a record that the user has access to.  This means that, when a report is already filtered to include only completed requests, the option ‘None’ will be the only one offered when the user adds the Target indication filter.
