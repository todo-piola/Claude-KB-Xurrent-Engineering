# New Filters for Request Templates

Request templates can now be filtered by change manager and by change template.  This can be useful, for example, when someone from the organization needs to find request templates that are linked to a specific change template and a new person needs to be made responsible for the new changes that are generated when these request templates are applied.

If, for example, Tom Waters has left the organization and Frank Watson needs to take over his responsibilities, all request templates in which Tom is selected in the Change manager field can be updated at once.  To do this, someone with Service Desk Manager role can click on the vertical ellipsis next to the filter icon and select the ‘Edit All…’ option.  This causes the [Mass Update](https://www.xurrent.com/product-updates/mass-update-request-templates) dialog window to appear in which Frank Watson can be selected as the new change manager for all request templates in the view:
