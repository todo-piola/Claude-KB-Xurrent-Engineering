# Average Time to SLA Response Reports

Because most support organizations are not only tracking their SLA resolution targets, but also their SLA response targets, the following three reports have been added to the ‘Reports’ section of the Analytics console:

- Average Time to SLA Response by Request Category
- Average Time to SLA Response by Service
- Average Time to SLA Response

A similar set of reports was already available for [SLA resolution targets](https://www.xurrent.com/product-updates/average-time-to-sla-resolution).
