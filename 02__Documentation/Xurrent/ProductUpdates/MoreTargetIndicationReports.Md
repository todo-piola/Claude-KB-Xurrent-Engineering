# More Target Indication Reports

Several new reports have been added to the ‘Reports’ section of the Analytics console to help organizations generate an overview of the records that are in danger of not meeting their target.

The following two reports already existed:

- [Open Requests by Target Indication](https://www.xurrent.com/product-updates/open-requests-by-target-indication)
- [Active Problems by Target Indication](https://www.xurrent.com/product-updates/more-problem-management-reports)

The new reports that have become available are:

- Open Releases by Target Indication
- Open Changes by Target Indication
- Open Tasks by Target Indication
- Open Projects by Target Indication
- Open Project Tasks by Target Indication
