# Filter Project Task Views and Reports by Program

It was already possible in Xurrent to filter project views and reports by program.  This is important for program managers who want to keep track of all open projects that are part of their program.  They could, for example, prepare a dashboard to help them visualize the state of their program.

Because the Program filter is now also available for views and reports of project tasks, it makes sense for program managers to also include project task reports in the dashboard they use to track their program.  When they apply the Program filter to this dashboard, it affects both the project reports and the project task reports.
