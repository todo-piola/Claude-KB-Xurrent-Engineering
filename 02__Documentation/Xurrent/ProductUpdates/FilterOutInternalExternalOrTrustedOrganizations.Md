# Filter Out Internal, External or Trusted Organizations

A few months ago it became possible in Xurrent to easily distinguish between [internal, external and trusted organizations](https://www.xurrent.com/blog/identify-external-and-trusted-organizations). The next logical step would be to allow the organization views and reports to be filtered by organization type. That’s why the ‘Type’ filter has now been added.

The ‘Type’ filter makes it possible to limit the organizations in a view or report to those that are internal, external and/or trusted.
