# Place Problems on Agile Boards

When the [Agile Boards](https://www.xurrent.com/product-updates/introducing-agile-boards) functionality was introduced a few weeks ago, only requests could be placed on agile boards.  Now it is possible to also work on problems from an agile board.

There is no need to make any changes to existing agile boards.  The configuration of each column is respected for problems just like it is for requests.
