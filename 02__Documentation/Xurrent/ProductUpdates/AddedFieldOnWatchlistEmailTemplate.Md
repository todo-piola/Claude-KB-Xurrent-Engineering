# Added Field on Watchlist Email Template

The email template ‘Watchlist Item Updated’ is used to send notifications to users, which inform them of a status update or an added note to a request, problem, release, workflow, workflow task, project, or project task they are following using the Watchlist functionality. A new [template field](https://help.xurrent.com/help/email_template_fields/) has been added to this email template: request_requested_for_organization_name. It inserts the name of the organization to whom the person who requested the request belongs, into the notification email.
