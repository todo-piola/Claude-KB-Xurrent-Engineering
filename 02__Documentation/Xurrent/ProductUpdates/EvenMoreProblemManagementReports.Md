# Even More Problem Management Reports

Another set of problem management reports has been added to the ‘Reports’ section of the Analytics console.  This set is made up of the following reports:

- Active Problems by Manager
- Active Problems by Team
- Halted Problems by Manager
- Halted Problems by Team
- Solved Problems by Manager
- Solved Problems by Team

These additional reports should help support organizations improve the monitoring of the problem management workload of their teams and problem managers.
