# Search Phrase Field on Custom Views

[Custom views](https://help.xurrent.com/help/custom_view/) can be created for many of Xurrent®’s record types.  They can be linked to a UI extension, to create lists out of which user can select items.  Custom views can be filtered to ensure that only records that meet predefined requirements are included.  An additional way to filter these records is now available for custom views: search phrases.

The Search phrase field allows the custom view to be filtered on (part of) a keyword.  In the example below, a custom view is filtered on active configuration items with status ‘In Stock’.  The Search phrase field additionally filters on those configuration items with the word ‘laptop’ in their name.
