# End Users Can Withdraw Their Requests

After someone has submitted a request, it can happen that the requester no longer needs the request to be completed.  As long as the request has not already been completed, it is now possible for the person who submitted the request to withdraw it using [Xurrent Self Service](https://www.xurrent.com/features/self-service-portal) or the [Xurrent App](https://www.xurrent.com/product-updates/download-the-4me-app).

If the request was [submitted on behalf of someone else](https://www.xurrent.com/blog/do-not-allow-requests-to-be-submitted-for-others), this person can also withdraw it.  And when a [key contact](https://www.xurrent.com/product-updates/key-contacts) has access to the request, even this person is authorized to withdraw it.

To withdraw a request, the requester opens it in Xurrent Self Service or the Xurrent App.  If the requester is an end user or key contact, the **Withdraw** button will be available below the Note field as long as the request has not reached the ‘Completed’ status.

If the user presses the **Withdraw** button and the Note field is empty, the cursor is placed in the Note field and a message appears asking the user to specify the reason for withdrawing the request.

When the Note field contains text and the **Withdraw** button is pressed, the user is asked to confirm the withdrawal.  This avoids situations where a user intended to press the **Save** button, but accidentally pressed the **Withdraw** button.
