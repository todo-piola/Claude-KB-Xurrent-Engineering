# Two More SLA Filters

It is now common for Xurrent customers to manage hundreds of SLAs in their Xurrent account.  For managed service providers (MSPs) that use Xurrent the number of SLAs is typically in the thousands.  Because of these growing numbers, the ability to filter SLAs is becoming increasingly important.

To help people find specific SLAs, two more filters have become available for SLA views and reports.  The filters that were added are:

- Customer representative
- Service level manager
