# More Configuration Management Reports and Filters

A few more reports have been added to help configuration managers prepare their dashboards.  The reports that were added can be found in the ‘Reports’ section of the Analytics console.  They are called:

- Configuration Items by Product
- Configuration Items by Product Brand
- Configuration Items by Product Category

In addition, the following filters have been added for configuration item views and reports:

- Asset ID
- PO number

These filters are especially useful for finding the CIs that do not have a value in their Asset ID or PO number field.  That is because the operator of these filters can be switched from  `Equal to`  to  `None`.
