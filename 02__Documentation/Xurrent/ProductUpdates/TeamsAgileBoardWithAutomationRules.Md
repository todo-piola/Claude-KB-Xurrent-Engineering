# Team’s Agile Board with Automation Rules

It is now possible to create an automation rule that looks up the [agile board](https://www.xurrent.com/product-updates/introducing-agile-boards) of a team.  This makes it possible, for example, to create an automation rule that places a request on a team’s agile board, even when it was assigned directly to a specific team member.  Such an automation rule would overrule Xurrent’s default behavior that prevents assignments from getting added automatically to a team’s agile board when the Member field already has a value.
