# Desired Completion Filter

The filter ‘Desired Completion’ has been added to all request views and reports.  This filter can be used to exclude all requests, except for the ones that have a value in their [Desired completion field](https://www.xurrent.com/product-updates/desired-completion) that falls within a selected date range.

The quick range options also include the options [‘None’ and ‘Not none’](https://www.xurrent.com/product-updates/find-records-with-empty-date-fields).  These options make it easy to include only the requests that have an empty Desired completion field, or that have a value in their Desired completion field.  And, as for all date filters, it is possible to specify a [custom date range](https://www.xurrent.com/product-updates/custom-date-ranges-for-reports).
