# Custom Field Filters Grouped Together

A little while ago it became possible to [use the values in the custom fields of UI extensions to filter views and reports](https://www.xurrent.com/product-updates/custom-field-filters).  Because some custom fields may have been given the same name as a standard field of the Xurrent service, we decided to make it easier to distinguish between the custom fields and the standard fields.

People will now see that the custom fields have been grouped together at the bottom of the list when they start to apply a filter.  This has the added benefit that, if an organization has defined a large number of custom fields, they do not distract from the standard fields when someone is trying to select a new filter.
