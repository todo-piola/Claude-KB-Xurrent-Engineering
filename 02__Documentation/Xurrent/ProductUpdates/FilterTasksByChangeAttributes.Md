# Filter Tasks by Change Attributes

A few more filters have been added to make it possible to reduce a list of change tasks to those that are part of a change that matches specific attributes.  Specifically, the following filters have been added for change tasks:

- Change category
- Change type
- Justification

In addition, the ‘Service instance’ filter was added to allow implementation tasks to be filtered by the service instances that are linked to them.

These filters are available in the records console after a tasks view has been opened.  The same filters are available in the reports that are based on data from change tasks.
