# Filter Requests by Requester

Many customers have asked for the ability to filter the request views and reports by the person for whom a request was submitted.  To make this possible, the Requester filter has been added.  This filter looks at the person who is selected in the Requested for field of each request.

In addition, the following three reports have been added:

- Registered Requests by Requester
- Open Requests by Requester
- Completed Requests by Requester

It is likely that some organizations would rather not allow all their specialists to report on the number of requests submitted by each of the users they support.  That is why these [reports are disabled](https://www.xurrent.com/product-updates/disabling-reports) by default.
