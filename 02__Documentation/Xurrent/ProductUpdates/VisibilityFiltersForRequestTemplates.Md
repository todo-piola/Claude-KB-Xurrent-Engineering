# Visibility Filters for Request Templates

It is now possible to filter the request templates view and reports by the communities that are allowed to use the templates.  The [visibility options for request templates](https://www.xurrent.com/blog/visibility-indicator-for-request-templates) are ‘End users’ and ‘Specialists’, so the following two filters were added:

- End users
- Specialists

**Pro Tip**
Some organizations have request templates that may only be applied to requests by integrations.  In such cases, neither visibility option is checked in these request templates.  In View mode, the visibility of such templates shows up as ‘API only’.

To filter out these templates, the filters ‘End users’ and ‘Specialists’ should be set to:  is not Yes
