# Specify Default Effort Class in Request Templates

A new feature has been added to help provider organizations that use Xurrent’s time tracking functionality for internal chargeback or invoicing their customers. If these organizations have activated [effort classes](https://www.xurrent.com/product-updates/introducing-effort-classes), they will now see the optional Default effort class field in their request templates.

When a template with a default effort class is applied to a request and the specialist enters a value in the Time spent field, this default effort class will be selected in the request’s Effort class field, provided that the specialist belongs to an organization which timesheet settings includes this effort class.
