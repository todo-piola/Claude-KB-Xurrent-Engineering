# Filter Task Templates by Change or Project Template

It has become very easy to look up all the task templates that are part of a specific change template or project template.  The filter ‘Change template’ is now available in the task templates views and reports.  Similarly, the filter ‘Project template’ is now available in the project task templates views and reports.

This filter is especially helpful when account administrators or account designers has prepared one or more change or project templates in QA and wants to [export](https://www.xurrent.com/product-updates/export-of-items-in-filtered-views) their tasks so that they can be imported in production.
