# Customize Accent Colors on Self Service Subpages

Earlier this year, [Self Service v2](https://www.xurrent.com/product-updates/introducing-4me-self-service-v2) was introduced, which gave organizations more flexibility and control over their self-service homepage and other elements, such as the navigation, header and footer. Since then, several enhancements have been delivered, adding a similar level of flexibility to the subpages. These include customizing the font, background color and image, [dark mode](https://www.xurrent.com/blog/dark-mode-on-self-service-subpages), and improvements to Search and the New Request Wizard. This release introduces the possibility to adjust the accent colors of the self-service subpages.

Three new color settings have been added to the Global Settings tab on the ‘Self Service Settings’ section of the Settings console. They allow specific colors to be used for buttons, accent colors, and accessibility colors on the subpages.

Different colors can be selected for Light mode and Dark mode. To select a color, it is possible to use a color picker, an RGB (red-green-blue) code, HSL (hue-saturation-lightness) or HEX code. The colors are used by the system to define other colors. For example, the hover color of the button is derived from the color that was picked for the regular button color.
