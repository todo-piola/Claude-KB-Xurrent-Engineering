# Print Highlighted Texts in PDFs

All rich text fields in Xurrent allow for text to be highlighted in any color.  This is a great feature which makes certain parts of the text stand out even more than bold or italic.  Using the Action button in the header bar or the [shortcut shift+P](https://www.xurrent.com/blog/simplified-shortcut-keys),  it is possible to print to a PDF file.  This is often used for textual documents, like knowledge articles or service offerings.  Xurrent’s Print to PDF converter in Xurrent now includes this highlighting, to make the selected text also stand out in print.
