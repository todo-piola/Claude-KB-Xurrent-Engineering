# Include Headers in Rich Text Fields

A few more text formatting options have become available.  The new options are primarily intended for support organizations that want to perfect their [knowledge articles](https://help.xurrent.com/help/knowledge_article/), but they are available in all rich text fields, including the Note field of requests.  This allows the instructions of a knowledge article to be pasted in a request’s Note field without loss of formatting.

The first of the new formatting options allows a paragraph to be turned into a header.  When the new Heading (H1) icon is pressed in the [text formatting bar](https://help.xurrent.com/help/text_formatting/), the user can select the header level.  This ranges from the main header H1, which makes the text quite large and bold, to the sub-sub-sub-header H4, which still makes the text bold, but increases the size only a little.

After a paragraph has been turned into a header, the heading icon can be pressed again to turn it into a normal paragraph again.

Other text formatting options that have recently been added are:

- [Insert Tables in Rich Text Fields](https://www.xurrent.com/product-updates/insert-tables-to-rich-text-fields)
- [Add Color to Text and Tables](https://www.xurrent.com/product-updates/add-color-to-text-and-tables)
- [Strikethrough Text](https://www.xurrent.com/product-updates/strikethrough-text)
- [Copy/Paste From Excel to Rich Text Fields](https://www.xurrent.com/blog/copy-paste-from-excel-to-rich-text-fields)
