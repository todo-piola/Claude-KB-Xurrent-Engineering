# Auto Translation for French Canadian, Dari and Traditional Chinese

[Auto translation](https://www.xurrent.com/product-updates/introducing-auto-translation) is one of the most beloved capabilities of Xurrent for organizations that support people in multiple languages.  This functionality now supports 3 more languages, bringing the total number of supported languages to 38.

The languages for which support has been added are:

- Chinese (Traditional)
- Dari
- French (Canada)

**Reminder** – People who are able to read multiple languages may prefer to always see the original text, rather than the auto-translated version for some languages.  They can click on their picture in the toolbar to select the ‘My Profile’ option in the User menu, after which they can open the ‘Personal Preferences’ section to select the languages that Xurrent should not translate for them.
