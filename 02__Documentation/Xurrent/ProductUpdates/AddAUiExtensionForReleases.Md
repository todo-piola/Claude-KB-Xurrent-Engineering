# Add a UI Extension for Releases

The UI extension functionality in Xurrent is used to add custom fields to a form.  This capability has now also become available for the Release form.  This means that organizations can add some additional fields for their release managers.

The values that are entered in the [custom fields of releases can be used to search](https://www.xurrent.com/product-updates/search-through-ui-extensions) for specific releases.  And these [custom fields can also be used as filters](https://www.xurrent.com/product-updates/custom-field-filters) for the release views and reports.
