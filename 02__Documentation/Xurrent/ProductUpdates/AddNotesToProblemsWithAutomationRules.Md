# Add Notes to Problems with Automation Rules

It is now possible to create automation rules that add a note to a problem when specific conditions are met.  This [automation rule](https://www.xurrent.com/product-updates/introducing-automation-rules) feature was already available for requests, changes, tasks, projects and project tasks.  Because there is demand from problem managers for automatically adding information to problems, this capability has been added.
