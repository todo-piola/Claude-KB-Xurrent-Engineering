# Three More Configuration Management Reports

A few more reports have been added to help configuration managers maintain an accurate CMDB.  The reports that were added are:

- Configuration Items by Service
- Configuration Items by Supplier
- Configuration Items by Support Team

For the convenience of the configuration managers, these reports have the filter  Active is Yes  applied to them by default.  This causes these reports to exclude the configuration items (CIs) with the status ‘Archived’,  ‘To Be Removed’,  ‘Lost or Stolen’ or ‘Removed’.
