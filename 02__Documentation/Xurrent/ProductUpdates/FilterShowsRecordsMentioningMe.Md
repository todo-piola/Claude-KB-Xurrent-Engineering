# Filter Shows Records Mentioning Me

A new filter has been added that can show users in which records they were mentioned. The ‘Mentioning me’ filter is available in the Specialist interface for all record types that allow mentioning:

- Requests
- Problems
- Release
- Changes
- Tasks
- Projects
- Project Tasks
- Risks
