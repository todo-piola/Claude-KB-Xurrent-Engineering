# Floating Toolbar for Rich Text Fields

Rich text boxes can become very long, for example when extensive instructions are placed in a [knowledge article](https://www.xurrent.com/product-updates/introducing-knowledge-management).  To format text at the beginning of the article would in those cases involve a lot of scrolling to the toolbar at the bottom the field.  The rich text toolbar has now been anchored to the bottom of the screen or window.  This floating toolbar makes it easier and faster to edit large note fields.
