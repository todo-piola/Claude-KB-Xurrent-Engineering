# Add a Team Field to UI Extensions

It was already possible for Xurrent account administrators and designers to include custom fields in a UI extension that allow users to select an [organization, site](https://www.xurrent.com/product-updates/add-organization-or-site-fields-to-ui-extensions) or [person](https://www.xurrent.com/product-updates/add-person-field-ui-extensions) record.  Because these fields behave just like the standard suggest fields in Xurrent, they allow users to enter a few characters or words to look up and select a specific Xurrent record.

Now it is also possible to add a suggest field to a UI extension that allows users to select a team record.  After expanding the ‘Snippets’ section of a UI extension, it is as easy as selecting the field type ‘team-suggest’.

For specialists, a custom team-suggest field looks and behaves just like the other suggest fields in the Xurrent service.

End users, however, are not allowed to select a team.  Administrators should therefore make sure that a custom team-suggest field does not become visible in Self Service for people who do not have the Specialist role.
