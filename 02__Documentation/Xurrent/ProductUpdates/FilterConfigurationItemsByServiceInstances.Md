# Filter Configuration Items by Service Instances

Configuration items (CIs) cannot only be related to a service; they can also be linked to a specific [service instance](https://help.xurrent.com/help/service_instance/) of the service that they are related to.  Software CIs can even be linked to multiple service instances.

To make it easy to look up a list of the assets that are part of a service instance, it is now possible to filter the configuration item views by one or more service instances.

The same ‘Service instance’ filter is now also available in the configuration item reports.
