# Retrieve All Records Included in a Report

A useful feature has become available for all reports in the ‘Reports’ section of the Analytics console. This new feature allows people to look up all records that are included in a report.  To access this new feature, open a report, press the **Actions** button in the toolbar and select the option ‘Show Underlying Data’ from the Actions menu.

The ‘Show Underlying Data’ option opens a view in a new browser tab that lists all records that were used to generate the report.

Once in this view, the standard export functionality can be used by clicking on the vertical ellipsis in the view header.  This makes it possible to obtain an export file that contains all the records that were included in a report.
