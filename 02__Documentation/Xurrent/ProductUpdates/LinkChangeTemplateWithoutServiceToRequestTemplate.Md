# Link Change Template Without Service to Request Template

It has become possible to link a request template to a change template, even when the change template is not linked to a service. This allows the same change template to be used for [multiple similar request templates](https://www.xurrent.com/product-updates/mass-update-request-templates) for different services.

This means that, once a service has been selected in a request template, all change templates that are linked to the same service can be linked to this request template, plus any change template that is not linked to a service.

When a request template, which is linked to change template that has an empty Service field, is applied to a request, a new change is generated based on the change template. This new change will be related to the service of the request template.
