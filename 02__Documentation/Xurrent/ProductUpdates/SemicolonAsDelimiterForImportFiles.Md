# Semicolon as Delimiter for Import Files

When [importing](https://help.xurrent.com/help/import/)records into Xurrent, a CSV (comma-separated values) file or TSV (tab-separated values) file can be used.  In countries where the decimal separator is a comma, double quotes need to be used to include the comma in the value, and not use it as a separator. This can be cumbersome, for some users. On the other hand, saving an Excel file as TSV has the disadvantage that Excel saves such a file with a .txt extension, adding the need to rename the file before importing into Xurrent.

To increase usability when importing records, the CSV file may now be either comma-separated or semicolon-separated.  Xurrent automatically detects which column separator is provided for each CSV file.
