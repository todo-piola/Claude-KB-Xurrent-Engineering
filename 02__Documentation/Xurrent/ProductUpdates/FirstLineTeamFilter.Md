# First Line Team Filter

The service and service instance views now have a new filter called ‘First line team’.  This filter makes it possible to limit the services or service instances listed in a view to those that have a specific first line team.

Note that the first line team of a service instance is automatically selected in the Team field of a request when someone submits a new request for the service instance using Xurrent Self Service or the Xurrent App.  It is also selected when a service desk analyst is registering new request concerning a service instance, which first line team the analyst is not a member of.
