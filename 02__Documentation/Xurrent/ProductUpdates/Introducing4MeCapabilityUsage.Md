# Introducing Xurrent Capability Usage

Whenever Xurrent introduces a new feature, that feature is automatically available to all customers. This way, in the last 12 months alone, organizations that use Xurrent have been able to start using features like [Scrum](https://www.xurrent.com/product-updates/introducing-scrum), the [Shop](https://www.xurrent.com/product-updates/introducing-the-4me-shop), [Support Chat](https://www.xurrent.com/product-updates/introducing-support-chat), [Billing](https://www.xurrent.com/blog/introducing-billing-integration-effort-classes), and much more, without the need to pay extra for it. With the large number of features and capabilities that are released and available within Xurrent, it might not always be clear for an organization if they are making the most out of the Xurrent service. The new ‘Xurrent Capability Usage’ section in the Settings console can then help.

At the top right of the screen, the current number of Xurrent Capabilities is displayed with the number of these that are in use by the account. Each of these capabilities is considered in use if a certain minimal level of activity was observed within it over the past period. Agile Boards, for example, are considered in use if at least 25 agile board items were created in the past 6 months. In that case, a green checkmark is placed on the card of the capability. Each card also contains a link to an article that explains how to get started with that capability.

In a directory account, a card shows a green checkmark if any of the support domain accounts have the card checked.
