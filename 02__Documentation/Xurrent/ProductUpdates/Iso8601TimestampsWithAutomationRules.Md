# ISO 8601 Timestamps With Automation Rules

Timestamps are essential for defining when a certain event occurred.  Many different formats for timestamps exist, depending on the needs of a system’s users.  ISO 8601 is an international standard covering the worldwide exchange and communication of date- and time-related data.  In order to facilitate organizations that use Xurrent date- and time-related data in other information systems, a new [automation rule operator](https://help.xurrent.com/help/automation_rule_operators/) has been added that can convert a timestamp to the ISO 8601 standard.
