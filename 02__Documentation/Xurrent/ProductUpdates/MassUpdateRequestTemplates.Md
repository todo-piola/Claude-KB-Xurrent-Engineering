# Mass Update Request Templates

The [Mass Update](https://www.xurrent.com/blog/mass-update-of-cmdb) functionality was introduced several months ago for configuration items.  Now it has been extended to [request templates](https://help.xurrent.com/help/request_template/).

This makes it possible for service desk managers to not only create many similar request templates using the [Duplicate](https://www.xurrent.com/product-updates/duplicate-templates) functionality, but also to maintain all of these templates without much effort.

To update multiple request templates, simply select them by holding down the Ctrl key (or the Command key on macOS) and clicking on the ones that require an update.  Holding down the Shift key allows a whole section of the view to be selected.

After selecting the templates that need to be updated, press the vertical ellipsis in the far right of the view’s header and select the ‘Edit Selected…’ option.
