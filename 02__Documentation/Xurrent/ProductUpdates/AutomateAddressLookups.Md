# Automate Address Lookups

Xurrent’s automation rules are now able to look up an address from a site.  This makes it pretty easy to set up an automation rule that, for example, is triggered when a task is assigned and looks up the address of the site where the person works who submitted the request for which the task’s change was registered.

Having retrieved the address, the automation rule can add a note to the task to make sure that the specialist handling the task does not need to manually look it up by opening the request.
