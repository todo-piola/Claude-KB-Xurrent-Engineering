# API Tokens Removed When Not Used

As an extra security measure, people no longer automatically get an [API token](https://www.xurrent.com/blog/securing-api-tokens) when their person record is created in the Xurrent.  Going forward, an API token is generated for a person when he/she first clicks on the **Reset API Token** button to see it.

Furthermore, Xurrent now automatically deletes an API token for a person when this token has not been used for more than 365 days.  [Administrators and auditors](https://help.xurrent.com/help/roles/) can see how long ago it has been since someone last used his/her API token in the ‘API Last Activity’ column.
