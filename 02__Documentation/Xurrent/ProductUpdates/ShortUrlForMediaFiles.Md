# Short URL for Media Files

[Short URLs](https://help.xurrent.com/help/short_url/) are used to shorten the long URLs of website addresses, or for creating QR codes to easily share knowledge articles, dashboards, surveys, and much more.  Short URLs can now also be created for media files that are stored in the Media Library, which can be found in the Settings console.

An additional advantage of this is that the short URL is a permanent link to the media file in the library, while the public link of a media file changes when the file is modified.  So if a short URL or QR code is sent in an email, it will remain valid even after the related file has been changed.
