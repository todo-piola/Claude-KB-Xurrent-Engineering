# Option for Horizontal Line in Reports

In most column and line charts, a new visualization option ‘Show horizontal line at…’ is now available. Selecting this option prompts the user to enter a number. A horizontal, dashed line is then added to the chart at the required height. This can be useful when an organization has set a limit to an acceptable percentage or number of occurrences, for example. Or it could indicate a benchmark or threshold.

In the following example, a horizontal line is added as a demarcation of the 85% level of requests with breached SLAs vs non-breached SLAs. It gives the person looking at the report an instant overview of the level of [customer SLA breaches](https://www.xurrent.com/blog/new-reports-on-customer-affected-slas) in the previous and current months.

A label can be given to the horizontal line, to make it clear what the line represents, exactly.
