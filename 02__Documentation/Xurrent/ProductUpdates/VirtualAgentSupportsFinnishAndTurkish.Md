# Virtual Agent Supports Finnish and Turkish

The [Xurrent Virtual Agent](https://www.xurrent.com/product-updates/introducing-the-4me-virtual-agent) is now able to interact with end users in the Finnish and Turkish languages.  Any user who has his or her language set to ‘suomi’ or ‘Türkçe’ will now be addressed by the virtual agent in Finnish or Turkish.
