# Report on Changes by Type

Three new change management reports have been added to the ‘Reports’ section of the Analytics console.  These three new reports are:

- Registered Changes by Type
- Open Changes by Type
- Completed Changes by Type

Because organizations can [customize the change types](https://www.xurrent.com/product-updates/customize-change-type-options) that they use to manage their changes, these reports can be quite useful for the organizations that use this ability.  Organizations that do not need to break down their change data by type will not have any change types enabled.  These reports are still available for them if they at some point decide to start using change types.
