# Filter Audit Entries

To make it easier for organizations to collect the evidence their [auditors](https://help.xurrent.com/help/audit/) ask for, two filters have been added to the views in the ‘Audit Entries’ section of the Settings console. The two filters that can now be applied are:

- Type – the record type that was created, updated or deleted
- User – the person who created, updated or deleted the record

In addition, the IP column has been added to the audit entry views to make it easier to detect anomalies.
