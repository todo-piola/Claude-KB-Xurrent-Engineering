# My Projects Option Added to Self Service

The menu option ‘My Projects’ is now available in Xurrent Self Service and the Xurrent App for all end users who have been added to at least one project task by a project manager.  This menu option allows them to obtain a list of all open and completed projects that include a registered, open or finished task to which their person record is linked as an assignee or approver.

When one of the projects is selected from the list, a high-level overview of the project opens.  This overview includes the project’s [Gantt chart](https://www.xurrent.com/blog/open-projects-and-changes-in-self-service).
