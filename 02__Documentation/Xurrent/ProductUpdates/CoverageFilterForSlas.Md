# Coverage Filter for SLAs

Another [new filter](https://www.xurrent.com/product-updates/two-more-sla-filters) has been added to the ‘Service Level Agreements’ view of the Records console.  The Coverage filter selects SLAs based on the defined [group of people that are covered for a certain SLA](https://www.xurrent.com/product-updates/more-sla-coverage-options).

When one or more of the SLAs listed in the view does not have a value in the Coverage field, the option ‘None’ is also available.  This limits the items in the view to the SLAs which Coverage field is empty.  Setting the Coverage filter to ‘None’, therefore, makes it easy to look up the SLAs which coverage still needs to be defined.
