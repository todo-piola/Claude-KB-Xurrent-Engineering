# Trigger Automation Rule on Template Application

A new trigger has become available for [automation rules](https://learning.xurrent.com/automation_rules_introduction/) that are created for [request templates](https://help.xurrent.com/help/request_template/) or requests.  The new trigger is called ‘On request template update’.

In the past it was not possible to trigger an automation rule when the only update made to an existing request was the update of the request’s template.  This new trigger makes that possible.

Note that the template of a request is also considered updated the first time a template is applied to the request, i.e. when the request’s Template field gets a value for the first time.  The new trigger also starts its automation rule after a template is applied to a new request and this new request is saved.
