# Change ID & Project ID Included in Time Entry Exports

The [time entry export files are special](https://www.xurrent.com/blog/service-provider-included-in-time-entry-exports) because many organizations rely on the data in these files as input for their automated internal chargeback or billing process.  To make it easier to include information about the changes and projects which tasks people spent time working on, the ID of the change or project that each task belongs to is now included when the time entries are exported.
