# Created At and Updated At Exported for Person Records

The Created At and Updated At columns have been added to the export files for person records. These columns are available in both the Comma-separated values (.csv) and Microsoft Excel (.xlsx) formats of these export files.

Having this data in the export files can help organizations build more efficient integrations for automatically maintaining employee data in their Xurrent directory account.
