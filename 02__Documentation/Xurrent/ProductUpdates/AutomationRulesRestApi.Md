# Automation Rules REST API

The Xurrent REST API capabilities have been extended again, this time to support developers who want to automate the retrieval, update and/or creation of automation rules.  They can now use the new Automation Rules API to do this for the automation rules in their organization’s Xurrent account.

This new API is documented in the Xurrent Developer documentation, which is available at: [https://developer.Xurrent.com/v1/automation_rules/](https://developer.xurrent.com/v1/automation_rules/).
