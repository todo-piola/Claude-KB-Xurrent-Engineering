# Report by Quarter

Now that it has become possible to [report over much longer date ranges](https://www.xurrent.com/blog/date-range-limit-for-reports-relaxed), the need to track trends by quarter has cropped up.  To make this possible, the interval option ‘Quarter’ has been added.  This new option is available for all reports with a date range on their X-axis (horizontal axis).

To set the time interval to ‘Quarter’, click on the date range filter at the top of the report.  This opens a dialog that offers a list of ‘Quick Ranges’.  In this dialog, switch to ‘Custom Range’.  Next, click on the Interval field and select the option ‘Quarter’.
