# Knowledge Article Life Cycle Report

A new knowledge management report has been added to the ‘Reports’ section of the Analytics console.  This report can be used by support organizations to see how actively knowledge articles are being added and maintained over time.

The new report is called ‘Knowledge Article Life Cycle’.  It tracks the number of articles by status over time.
