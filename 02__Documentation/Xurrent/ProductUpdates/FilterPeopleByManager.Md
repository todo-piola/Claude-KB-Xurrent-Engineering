# Filter People by Manager

The people views in the Records console can now be filtered by manager.  The ‘Manager’ filter was added to make it easy to find all people who have the same manager.

By filtering the list of people by a specific manager it becomes easy to check whether this information was correctly loaded into Xurrent, for example, from Azure AD, Okta or OneLogin.  Making sure that the manager information is correct is important for most organizations because it is typically needed for the automated assignment of a number of approval tasks within their standard changes.
