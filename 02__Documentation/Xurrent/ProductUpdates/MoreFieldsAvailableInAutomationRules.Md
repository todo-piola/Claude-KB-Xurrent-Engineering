# More Fields Available in Automation Rules

The values of a few more fields can be retrieved and manipulated using [automation rules](https://www.xurrent.com/product-updates/introducing-automation-rules).  The product fields Brand, Category, Model and Product ID have been added to the list of fields that can be used in automation rule expressions and actions.  And for organizations, the Region field has become available.
