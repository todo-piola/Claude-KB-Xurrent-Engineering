# Display Status in History Section

The ‘History’ section of the Configuration Item form now provides a bit more information. When this section is expanded, it now displays the status of every request, problem or task that is linked to the CI.

The same improvement has been implemented for the ‘[History](https://www.xurrent.com/product-updates/the-history-of-service-instances)‘ section of the Service Instance form. Seeing the current status of the assignments that are linked to a configuration item or service instance can help specialists identify activities that are still ongoing or planned and could potentially conflict with other work that needs to be performed.
