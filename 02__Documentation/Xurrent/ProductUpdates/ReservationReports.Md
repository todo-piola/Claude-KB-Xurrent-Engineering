# Reservation Reports

The ability to make [reservations](https://www.xurrent.com/product-updates/introducing-reservations) in Xurrent has triggered the need for some reports.  To satisfy this need, the following reports have been added:

- Reservations by Configuration Item
- Reservations by Person
- Reservations by Reservation Offering
- Reservations by Service
- Reservations by Service Instance

These reports can be filtered by the same filters that were already available for the ‘All Reservations’ view.  Two new filters have been added to this list to also make it possible to filter this view and the new reports by [service](https://help.xurrent.com/help/service) and [service instance](https://help.xurrent.com/help/service_instance).
