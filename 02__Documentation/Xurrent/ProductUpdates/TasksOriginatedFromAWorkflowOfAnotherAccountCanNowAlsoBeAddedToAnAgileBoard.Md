# Add Task From Other Account to Agile Board

[Agile boards or kanban boards](https://www.xurrent.com/product-updates/introducing-agile-boards) are a great way for teams to visualize and organize their agile development processes. In Xurrent, agile boards can contain requests, tasks, project tasks, and even problems. For requests, it doesn’t matter from which (trusted) account it originated, to be able to be added to an agile board. For tasks, it is now also possible to be added to an agile board, even if that task originated from a workflow of another account.
