# Adjust Default Grouping Filter for Request Reports

The request reports have always ignored [request groups](https://www.xurrent.com/blog/another-way-to-add-requests-to-a-group).  The request groups were not counted because they are merely placeholders to which multiple requests can be related.  So the request reports only counted requests that were either not linked to a group, or were linked to a group, but did not count the groups themselves.

This is still the case, but now users can adjust this default filter.  When they open a request report, they will see this default filter explicitly presented above the report.

Because the filter is now visible, it can be adjusted.  This makes it possible to, for example, report on request groups only.
