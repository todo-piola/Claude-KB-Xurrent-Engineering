# Email Broadcasts

A [broadcast](https://www.xurrent.com/blog/new-recipient-selections-for-broadcasts)is used to present a message for end users and/or specialists when they access Xurrent. So far, four different types of messages could be broadcast: outages, availability, warnings, and information. A fifth option has now been added to the Broadcast feature: sending an email to selected Xurrent users.

This new feature becomes available after creating an email template of type ‘Broadcast’ and action ‘Send Email From Broadcast’. Sending an email instead of a broadcast can be especially useful when people should be notified of a change or an incident but have no access to Xurrent.

So far, only one option is available for selecting recipients: Customer representatives of specific service level agreements. This option has also been added to the other broadcast message types. More email recipient options will be added in later iterations of this feature.
