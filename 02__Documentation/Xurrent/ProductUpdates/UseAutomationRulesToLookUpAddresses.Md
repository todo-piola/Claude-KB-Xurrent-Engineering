# Use Automation Rules to Look Up Addresses

It was already possible to use [automation rules to look up the addresses of sites](https://www.xurrent.com/product-updates/automate-address-lookups).  Now it is also possible to create an automation rule that automatically retrieves the address of an organization, or the address information from the contact details of a person.  This makes it possible, for example, to use the addresses of every shop of a retailer organization in an email template.
