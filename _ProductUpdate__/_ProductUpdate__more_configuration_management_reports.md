# More Configuration Management Reports

To help configuration managers maintain the information about their assets in the configuration management database ([CMDB](https://www.xurrent.com/blog/afraid-of-the-cmdb)), the following reports have been added:

- Configuration Items by Site
- Configuration Items by Location
- Configuration Items by Service Instance
- Configuration Items by Depreciation Method

These four new reports can be found in the ‘Reports’ section of the Analytics console.

For organizations that maintain the financial information about their assets in their CMDB, the ‘Depreciation method’ filter has been added.  Apart from being available in the configuration item reports, this filter is also available in all the configuration item views of the Records console.
