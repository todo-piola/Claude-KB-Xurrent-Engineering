# Media Library Improvements

The [media library](https://www.xurrent.com/product-updates/introducing-the-media-library), which is available in the Settings console, makes it possible for people to store files such as images and videos in their organization’s Xurrent account.  After a file is stored in the media library, it becomes possible to link to this file from, for example, knowledge articles or the account’s self service design.

When people open the ‘Media Library’ section of the Settings console, they will notice that the ‘Media Files’ view has three extra columns, namely: Created By, Created and Updated.

Sorting by these columns should make it easier to find specific files in the media library.  To make this even easier, the ability to filter the ‘Media Files’ view by the values in these three new columns has also been added.
