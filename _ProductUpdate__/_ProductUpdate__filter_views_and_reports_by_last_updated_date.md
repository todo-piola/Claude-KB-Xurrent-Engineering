# Filter Views and Reports by Last Updated Date

Yet another filter has become available.  This new filter is called ‘Updated’ and it makes it possible to use the date on which a record was last updated to filter the views in the Records console and the reports in the Analytics console.

By setting a date range for the ‘Updated’ filter, only the records that were updated within this date range are included in the view or report.  If a record has never been updated, Xurrent takes the creation date of this record as the date on which it was last updated.
