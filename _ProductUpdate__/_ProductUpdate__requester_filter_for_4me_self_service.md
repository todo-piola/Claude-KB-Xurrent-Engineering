# Requester Filter for Xurrent Self Service

A new filter has been added for the All Requests view in [Xurrent Self Service](https://www.xurrent.com/features/self-service-portal).  With the Requester filter, only requests from a specified requester is shown.  This filter works on the Requested For field, not the Requested By field.
