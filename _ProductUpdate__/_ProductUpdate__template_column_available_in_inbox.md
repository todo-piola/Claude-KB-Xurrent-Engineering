# Template Column Available in Inbox

Requests, tasks, and project tasks can all be created from or related to a template.  Within their respective views it was already possible to show the related template, by customizing the columns of that view.  Now it is also possible to add the ‘Template’ column to the Inbox.  This is, of course, especially useful for requests.  Being able to see – and sort on – the request template subject can give the user a better overview of the type of assignments that are in the inbox.

Filters for ‘Project task template’, ‘Request template’, and ‘Task template’ were also added to the Inbox.
