# Recurring Filtered Exports

Not too long ago, an enhancement of the export functionality from views made it possible to [export a view with personalized columns](https://www.xurrent.com/product-updates/export-customized-views), filters, and sorting. A new enhancement has been made to this feature, which makes it possible to schedule exports created from any view that supports exports, accessed via the ellipses menu (3 vertical dots). This includes ‘Requests’, ‘Configuration Items’, ‘Custom Views’, and many more.

After configuring the frequency of the export and pressing the **Export** button, the exports are scheduled and a message is shown when the first run will be, and that the export can be downloaded from a notification email.

The scheduled exports can be accessed from the ‘Exports’ section in the Settings console. There, the frequency can be adjusted, if necessary.
