# Automatic Incident Registration From Tasks

It was already possible to cause a task within a change workflow to [generate a new request](https://www.xurrent.com/blog/generate-a-new-request-from-a-task) based on a request template with the category ‘RFC’ or ‘RFI’.  This can be configured by a change manager in the ‘Request Generation’ section of the task template.  Now it is also possible to have a task automatically generate a request from a request template with the category ‘Incident’.  This can be helpful for organizations that want to automatically register incidents based on the outcome of inspection tasks, for example.

Request templates with the categories ‘RFC’, ‘RFI’ and ‘Incident’ can also be selected dynamically in the Request template field by an [automation rule](https://www.xurrent.com/product-updates/automation-rules-create-requests-from-tasks).
