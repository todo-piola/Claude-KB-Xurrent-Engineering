# AI Sentiment of Requestor

[Xurrent AI](https://www.xurrent.com/platform/ai-service-desk) is now powering a ‘Sentiment’ indicator for the requestor at the individual request level. The conversation within a request is passed to our Amazon Bedrock LLM and we ask ‘What’s the sentiment of this request.’ As more notes are added the sentiment will re-calculate providing a trending indication. This feature when enabled will calculate only when new notes are added. The feature is not being backfilled to older requests.
