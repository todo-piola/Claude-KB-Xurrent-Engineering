# Invoice Depreciation and Amortization

When an [invoice is linked to a configuration item](https://www.xurrent.com/product-updates/invoices-for-configuration-items), the financial manager can choose the depreciation method.  When an [invoice is linked to a change, contract, SLA, FLSA](https://www.xurrent.com/product-updates/invoices-for-changes-contracts-slas-flsas) or project, an ‘Amortize’ checkbox is shown.  This checkbox replaces the deprecated ‘Capital expenditure’ checkbox.  When the ‘Amortize’ checkbox is checked, the following 2 date fields become available:

- Amortization start
- Amortization end

These dates will in the next release be used to generate expense records for the amortization of these invoices.
