# Trigger Automation Rule on Satisfaction Update

The trigger ‘On satisfaction update’ has become available for request and request template [automation rules](https://www.xurrent.com/product-updates/introducing-automation-rules).  This new trigger is especially useful for service providers that want to notify people after a requester has indicated to be dissatisfied with the way a request has been handled.

They can use this new trigger to inform, for example, the owner of the service that is related to the service instance of the request.
