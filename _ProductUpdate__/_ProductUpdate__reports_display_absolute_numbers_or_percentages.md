# Reports Display Absolute Numbers or Percentages

Pie charts, donut charts, and (ungrouped) bar charts can now show either absolute numbers or percentages.  For this, the option ‘Show percentage’ is added to these reports.  When placing the mouse pointer over any of the sections of the graph, the tooltip shows both the absolute number and the percentage value.

When adding a report that is shown in percentages to a dashboard, this setting is used there, too.
