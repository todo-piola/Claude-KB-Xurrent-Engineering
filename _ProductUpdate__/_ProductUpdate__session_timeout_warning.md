# Session Timeout Warning

Xurrent account owners are able to specify how quickly someone’s Xurrent session should be terminated after that person stopped working in Xurrent.  The [idle session timeout](https://www.xurrent.com/product-updates/idle-session-timeout) can be set in the Security section of the Settings console.

What is new is the 60 seconds warning that pops up before an inactive user’s session is about to get terminated.  At the same time, Xurrent displays a warning at the top of the browser windows in which Xurrent is open.

If the user shows no further activity during the next 60 seconds, the user is automatically logged out.

At this point the user’s unsaved changes will be lost, so it is important to take this into account when the account owner sets the idle session timeout for the account.  Clearing the browser window like this is an extra security measure that helps support organizations keep their Xurrent information private.
