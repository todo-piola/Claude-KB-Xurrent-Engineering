# Automation Rules for Team Coordinators

A new parameter has become available that allows administrators and account designers to define [automation rules](https://www.xurrent.com/product-updates/introducing-automation-rules) that look up the person who is currently acting as the coordinator for a team.

This parameter makes it possible, for example, to define an automation rule that causes a notification to be sent to the team coordinator when a note is added to a request that is not yet assigned to a specific member.
