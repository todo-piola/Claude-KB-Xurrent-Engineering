# Automatically Add Team Assignments to Agile Board

After an [agile board](https://www.xurrent.com/product-updates/introducing-agile-boards) has been set up for a team, this team may want all work that is assigned to the team to be placed in the first column of its agile board.  This can of course be achieved using [automation rules](https://www.xurrent.com/product-updates/introducing-automation-rules), but since this is such a common requirement, it is now possible to automate this by simply linking the agile board to the team.

An agile board can be related to a team by the team’s manager, or by an administrator of the account in which the team is registered.
