# Limit Number of Selectable Items in Custom Fields

It is now possible to specify the number of items that users are allowed to select in the suggest fields of UI extensions.  When selecting the Multiple values checkbox for a UI extension suggest field, it is possible to indicate the minimum and the maximum number of items that users can select in the field.

It may be good to point out that the highest number that an administrator or designer can specify as the maximum is 100.

As soon as a user selects more than the maximum number of items in a custom suggest field, a warning is displayed to ensure that it is clear why it is not possible to select more items.

This new customization feature is also available for the recently introduced [custom collections](https://www.xurrent.com/product-updates/introducing-custom-collections).
