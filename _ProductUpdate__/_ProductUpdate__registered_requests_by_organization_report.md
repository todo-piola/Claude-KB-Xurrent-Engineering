# Registered Requests by Organization Report

There were already two reports that provide an overview of requests by organization, where the organization is the organization that was linked to the person record at the time it was selected in the Requested for field of a request. These two reports are:

- Open Requests by Organization
- Completed Requests by Organization

But this meant that the following report was missing:

- Registered Requests by Organization

This omission has now been corrected. The ‘Registered Requests by Organization’ is can be found in the ‘Reports’ section of the Analytics console.
