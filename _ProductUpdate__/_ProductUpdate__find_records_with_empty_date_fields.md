# Find Records With Empty Date Fields

The filters that are available in views and reports for date fields now make it possible to look up records in which a date field is empty.  This allows configuration managers, for example, to identify the configuration item ([CI](https://help.xurrent.com/help/configuration_item/)) records in which the start date or warranty expiry date is not yet filled out.

This special date filter option is called ‘None’ and can be found at the bottom of the list of quick ranges.  There the opposite option ‘Not none’ is also available.

There are quite a few date fields that are always required, like the Created field which is automatically filled out when a new record is registered.  When filtering on such date fields, the filter options ‘None’ and ‘Not none’ do not provide any benefit, so they are not offered.
