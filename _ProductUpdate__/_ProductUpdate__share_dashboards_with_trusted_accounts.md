# Share Dashboards With Trusted Accounts

Account administrators, account designers, and service level managers could already [share a dashboard with customer representatives](https://www.xurrent.com/product-updates/customer-representative-can-see-all-requests)of selected SLAs in the current account or a support domain account. This functionality has now been extended, so that service providers can now share dashboards to customer representatives of the trusted (external) account of a customer.

Nothing in the user interface has changed; it was already possible to select the SLAs / customer representatives of trusted accounts, but Xurrent did not allow sharing over a trust. Now it does.

In the example above, taken from the GlobalNet account of the Xurrent Demo environment, Frederic Anderson shares a dashboard with the customer representative from Widget Data Center. The visibility options and the options with whom a dashboard should be shared will be refactored. This will likely be in next week’s release.
