# Filter Requests by Region

An additional filter has been made available for request views and reports. The filter is called ‘Organization region’.  It allows support organizations to limit a report to the requests that were submitted for people who work for the parts of the organization that are located in a specific region.

This filter can also be used to compare, for example, the number of requests from each supported region in a [dashboard](https://www.xurrent.com/product-updates/build-your-own-dashboards).
