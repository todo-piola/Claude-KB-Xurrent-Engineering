# Export Selected Automation Rules

Xurrent administrators and designers are now able to open the ‘[Automation Rules](https://www.xurrent.com/product-updates/introducing-automation-rules)‘ section of the Settings console and only export some of their organization’s automation rules.

This can be especially useful after a few new automation rule have been prepared and tested in QA.  By exporting only the new automation rule, the export file can be used more readily to import these new rules into production.
