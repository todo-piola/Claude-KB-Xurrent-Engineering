# Dynamic Filters in UI Extension Designer

Account designers and administrators can now add dynamic filters to custom-suggest fields in UI extensions created with the [UI extension Designer](https://www.xurrent.com/blog/introducing-the-ui-extension-designer). These filters can be used to filter on the ‘Requested for’ and the ‘Site of requested for’ in UI extensions of the category Request Template. After the custom-suggest field is added, a filter option appears:

The filters can work on person or site type records. For example, a filter on a configuration item custom-suggest field can be related to the service owner, the user, or the site. These can then be filtered: ‘User is Requested for’, or ‘Site is Site of Requested for’ etc.

After relating this UI extension to a request template, and from that template a request is registered for a person, only the CIs related to that user are now available for selection.
