# ID Column Added to Notes Export File

The ID column has been added to the notes export files.  Having the ID available in the notes exports can be useful, especially now that Xurrent is linking notes to time entries.

This makes it possible for the ID of a [note that is included in a time entries export file](https://www.xurrent.com/blog/show-related-note-in-time-entries) to be found in a notes export file using, for example, an Excel lookup function.
