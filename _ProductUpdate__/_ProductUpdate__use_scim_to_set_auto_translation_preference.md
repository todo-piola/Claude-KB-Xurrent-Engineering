# Use SCIM to Set Auto Translation Preference

Organizations that automatically maintain the Xurrent person records of their employees using [Xurrent’s SCIM provisioning capability](https://developer.xurrent.com/v1/scim/) were already able to set the language preference for these people.  Now they can also set their [auto translation](https://www.xurrent.com/product-updates/introducing-auto-translation) preference.

This can be useful for organizations that want to enforce a strict language standard for internal communication.  They can now add an action to their SCIM user automation rule to automatically switch off the auto-translation option when a person record is created or updated by the SCIM provisioning capability.
