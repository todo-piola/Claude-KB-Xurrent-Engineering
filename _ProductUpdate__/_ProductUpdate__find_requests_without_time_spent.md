# Find Requests Without Time Spent

There are a few reports that make it easy for service provider organizations to see if there are any requests from customers on which they are spending an exceptional amount of time.  These reports are:

- Time Spent on Open Requests
- Time Spent on Open Requests and Related Changes
- Time Spent on Completed Requests
- Time Spent on Completed Requests and Related Changes

It turns out, though, that providers want to also use these reports to see which requests (and tasks of the related changes) their people have not spent any time on.  Such requests may warrant a quick look to ensure that people did not forget to register the time they spent on them.  That is why an extra vertical bar has been added to these reports.  This bar contains the number of requests on which exactly zero time has been registered.

Now that the`0 hours`column has been added, the`0 – 1`hour bar contains the requests on which at least 1 minute and no more than 60 minutes have been spent.
