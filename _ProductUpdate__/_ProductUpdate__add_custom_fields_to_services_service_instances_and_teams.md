# Add Custom Fields to Services, Service Instances and Teams

Organizations can extend the user interface of their Xurrent account by adding custom fields to some of their records.  People who have the Account Designer or Account Administrator role can do this using [Xurrent’s UI extension functionality](https://www.xurrent.com/blog/advanced-ui-extension-examples).  What’s new is the possibility to define a UI extension for the following records types:

- [Service](https://help.xurrent.com/help/service)
- [Service instance](https://help.xurrent.com/help/service_instance)
- [Team](https://help.xurrent.com/help/team)

This makes it possible, for example, to add more information in each service instance record.

As with the UI extensions for other record types, the fields included in these new UI extensions can be made ‘[Internal](https://www.xurrent.com/product-updates/adding-fields-for-internal-use-only)‘ to ensure only the auditors, specialists, account designers and account administrators of the Xurrent account in which they are registered can see them.  The custom fields can also be made ‘[Searchable](https://www.xurrent.com/product-updates/search-through-ui-extensions)‘ and ‘[Filterable](https://www.xurrent.com/product-updates/custom-field-filters)‘.

The ability to add fields to service instances is especially useful for managed service providers (MSPs).  It allows them to share the specifications of the environments they make available to customers with their support experts.  Being able to filter the service instances view makes it easy for them to find, for example, the instances for which a recovery plan still needs to be written, that require an upgrade, or need to be moved to a different pricing plan.
