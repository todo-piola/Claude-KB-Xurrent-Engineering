# Completion Reason Filter for SLA Resolutions Reports

The filter ‘Completion reason’ has been added to the reports that make use of the SLA resolution target data of affected SLAs.  This makes it possible to limit these reports to the data from affected SLAs that are related to requests that are already completed and in which a specific completion reason was selected.
