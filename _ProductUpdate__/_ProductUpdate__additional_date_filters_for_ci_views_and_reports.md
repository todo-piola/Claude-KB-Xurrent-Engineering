# Additional Date Filters for CI Views and Reports

Three new date filters have been added for the configuration item (CI) views and reports. These filters make use of the following date fields and have the same name:

- License expiry date
- Start date  (= typically the purchase or invoice date)
- Warranty expiry date

These new filters make it possible to look up the software licenses that are about to expire, the assets purchased in a given period, or the CIs with an upcoming warranty expiration.
