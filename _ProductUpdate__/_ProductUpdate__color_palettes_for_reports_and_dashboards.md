# Color Palettes for Reports and Dashboards

A new customization option has been added to Xurrent. Designers and administrators can now  define color palettes to customize the colors in which reports and [dashboards](https://help.xurrent.com/help/dashboard/)are presented. This can be useful for presenting data to external stakeholders, creating an inbox dashboard in the corporate colors, or for MSPs when presenting dashboards to their customers, to name a few use cases.

The new ‘Color Palettes’ section has been added to the Settings console.

Here, colors can be defined for each type or report available in the ‘Dashboards’ and ‘Reports’ sections of the Analytics console. With the color palette in ‘Edit’ mode, a color can be adjusted by clicking on its square. Several methods for selecting the desired color are available, including point and click, entering RGB, HSL or HEX values, and a color picker.

Color palettes can be applied to the account (using the new Color palette field in the ‘Account Design’ section of the Settings console)  and / or to specific dashboards, as long as at least one active color palette exists. This works as follows:

- If a color palette is selected in a dashboard, then this color palette is used for all reports shown on the dashboard.
- If a color palette is selected in the account design, this palette is used for all reports in the ‘Reports’ section of the Analytics console, in all dashboards that do not have a color palette selected, and in the cumulative flow report of agile boards.
- If no color palette is selected in the account design, the in-built Xurrent palette is used for all reports in the ‘Reports’ section of the Analytics console, in all dashboards that do not have a color palette selected, and in the cumulative flow report of agile boards.
