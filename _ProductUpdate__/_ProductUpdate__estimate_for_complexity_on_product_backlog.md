# Estimate for Complexity on Product Backlog

A little while ago, [product backlogs](https://www.xurrent.com/product-updates/introducing-product-backlogs) were introduced, as a first step to providing Scrum support in Xurrent. It is now possible to add an estimate for complexity for each of the items on a backlog, often referred to as ‘story points’ within the [Scrum framework](https://www.scrum.org/). This is basically a unit of measure for expressing an estimate of the overall effort required to fully implement a product backlog item.

This estimate can be updated when editing a request or problem. The Estimate field is available when the status of the request or problem is ‘On backlog’.

Estimates on backlog items are an essential feature for Scrum teams when planning a sprint. The possibility to start and end sprints, the possibility to update the estimate directly on the backlog and more will be added in future releases.
