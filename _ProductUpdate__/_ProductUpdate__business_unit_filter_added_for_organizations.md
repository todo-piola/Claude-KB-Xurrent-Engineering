# Business Unit Filter Added for Organizations

The views that list organizations now have an addition filter called ‘Business unit’.  This new filter can be used to limit the organizations to just those in which the Business unit box is checked.

Naturally, the[`is not`](https://www.xurrent.com/product-updates/new-filter-option-is-not)filter option can be used to show all organizations that are not a business unit, or the filter can be defined as:`Business unit is No`.
