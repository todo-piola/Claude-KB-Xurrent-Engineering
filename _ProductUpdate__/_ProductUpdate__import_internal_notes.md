# Import Internal Notes

When an organization migrates from their previous solution to Xurrent, they generally want to import their legacy data, including requests.  For this, an import CSV file can be created, which also includes all the notes that were present in the original requests.  It is now possible to distinguish between internal and public notes in the import file.  Next to the already existing ‘Notes’ column, an ‘Internal Notes’ column can now also be included.

If it is important to retain the original order of the notes, the notes should be added using multiple imports or using the API.
