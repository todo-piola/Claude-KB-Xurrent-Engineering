# Import & Export Trusted Organizations

It recently became possible to [add information to the organization records of external customers and external providers](https://www.xurrent.com/product-updates/make-use-of-organization-records-from-trusted-accounts).  Because some providers have many external customers, there is now a need to efficiently add information to the organization records of these external customers.

That is why the import functionality has been extended to allow information to be added to the organization records of customers and providers that are registered in a [trusted Xurrent account](https://help.xurrent.com/help/account_trust/).  Xurrent administrators can make use of this option by going to the Records console, selecting ‘Organizations’, clicking on the **Actions** button in the toolbar, and selecting the ‘Import…’ option.  This makes it possible to initiate an import of data for organizations that are stored in a trusted account.

Similarly, the ‘Export…’ option of the Actions menu makes it possible to export the data that has been added to the trusted organizations.

Note that an export file contains only the trusted organizations to which information has been added by the account from which the export was performed.  That is because only those trusted organizations have gotten a corresponding record in the exporting account.
