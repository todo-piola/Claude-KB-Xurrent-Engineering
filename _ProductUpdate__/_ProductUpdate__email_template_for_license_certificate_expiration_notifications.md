# Email Template for License Certificate Expiration Notifications

An extra email template has become available.  Account administrators and designers can find it in the ‘Email Templates’ section of the Settings console.  It is disabled by default.

When this template is enabled, Xurrent sends out an email notification when a software license certificate is about to expire.  Specifically, these emails are send out 28 days, 7 days, 3 days and 1 day before a license expiry date.

Only the configuration manager of the support team of the license certificate receives these emails.  If a configuration manager is not selected in the support team record, then every person in the support team who has the Configuration Manager role of the support team’s Xurrent account gets notified.
