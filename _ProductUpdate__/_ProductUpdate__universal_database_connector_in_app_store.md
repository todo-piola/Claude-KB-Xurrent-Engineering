# Universal Database Connector in App Store

You can now easily connect Power BI and other reporting tools with Xurrent. The Power BI / Xurrent Database connector application is available from the Xurrent App Store. This new capability allows organizations to seamlessly export large volumes of data on a regular basis to a configured Microsoft SQL database to enable use of Power BI, Tableau, Qlik, Looker, and any other reporting application. To get started, simply set up an authorized Xurrent user in your database, input the relevant connection string into Xurrent, and you’re ready to go.

The app supports syncing data every 15 minutes, with a 1 hour delay on the synced data, all adhering to Xurrent’s standard rate limitation practices. This integration empowers you to create and update comprehensive, tailored reports and analytics, enabling deeper insights and more effective decision-making on top of the existing reporting capabilities in Xurrent.

For guidance on installation, refer to the Knowledge Article _Installing and Configuring the Xurrent Universal Database Connector App_in your QA environment.
