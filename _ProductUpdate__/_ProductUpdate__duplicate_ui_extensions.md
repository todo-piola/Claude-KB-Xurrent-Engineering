# Duplicate UI Extensions

It is now possible to duplicate [UI extensions](https://www.xurrent.com/blog/advanced-ui-extension-examples).  This is especially useful when an account designer or administrator has to create many similar UI extensions.  Instead of creating them all from scratch, they can now be copied and adjusted.

To duplicate a UI extension, first select it in the view (in the ‘UI Extensions’ section of the Settings console).  Then, click the Actions button and select ‘Duplicate UI Extension’ (or use the shortcut SHIFT + d).  A copy of the UI extension immediately opens, which can be edited and then saved and activated.

This apparently simple enhancement will bring great usability benefits for the power users of UI extensions.
