# Specialists Can Reassign Project Tasks

People who have the [Specialist role](https://help.xurrent.com/help/specialist_role) have always been able to update the assignment of change tasks.  Now they can do the same with project tasks.  This makes it possible for specialists who receive a task from a project manager, to forward this task to a colleague who may have a little more time or has more experience completing similar tasks.

Having this ability avoids the need for specialists and team coordinators to contact the manager of a project when one of the project’s tasks needs to be reassigned.  If the manager of a skill pool has the Specialist role, this person is now also able to assign project tasks to a member of the skill pool, or to an altogether different skill pool, team or person.
