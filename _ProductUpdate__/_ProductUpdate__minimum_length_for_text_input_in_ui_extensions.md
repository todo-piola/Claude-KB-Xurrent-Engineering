# Minimum Length for Text Input in UI Extensions

It was already possible for account designers to define a maximum length of a text field within a[UI extension](https://help.xurrent.com/help/ui_extension), using the HTML attribute maxlength.  Now, it is also possible to define a minimum length for a text field, using the HTML attribute minlength.  This can be important to ascertain that data remains legible, or to comply with restrictions imposed by interconnected systems, for example.

When typing text in a UI extension field with a minimum length restriction, the characters appear in red until the minimum length has been reached.
