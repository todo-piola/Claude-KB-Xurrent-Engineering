# Filter Products and CIs by Model

New filters have been added for the product and configuration items record types.  In the ‘Products’ view, products can now be filtered on ‘model’.  In the ‘Configuration Items’ view, CIs can now be filtered on ‘product model’.

When choosing the ‘model’ or ‘product model’ filter, the user has the option to filter on a partial match with a search term, a complete match, or filter for product or CI records that have no model registered.

As the ‘product model’ filter has been added to the configuration items record type, it can also be selected as a filter for a reservation offering.  This can be useful, for example, when a reservation of a laptop can only be made for a specific model, like the Dell Precision M4400 Laptop PC.
