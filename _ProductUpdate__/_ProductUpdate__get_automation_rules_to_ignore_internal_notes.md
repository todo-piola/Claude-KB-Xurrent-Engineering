# Get Automation Rules to Ignore Internal Notes

A new Boolean property has become available for [automation rules](https://www.xurrent.com/product-updates/introducing-automation-rules).  This property makes it possible to ignore internal notes that have been added to requests.  The new property is called  public.  The screenshot below presents a simple example of how this property can be used in an automation rule.

Because it is a Boolean, it can also be used to ignore any public notes.  This is done by simply changing  public = true  to  public = false.
