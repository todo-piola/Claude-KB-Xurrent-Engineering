# Custom Views Can Access Releases

Custom views can be created for many of Xurrent’s record types, including [custom collections](https://www.xurrent.com/product-updates/introducing-custom-collections). They can be used as filtered views, showing only records that meet predefined requirements. The ‘Release’ record type has now been added to the list of record types that are available for custom views. This can be useful for organizations that embrace release management and want users to select a specific release from a UI extension on a request template, for example. The screenshot below shows a custom view for releases, that is filtered on the status ‘registered’.

After creating a custom view, a UI extension can be created with a custom suggest field and linked to the custom view. This way, users can select a release from a pre-filtered list of releases, even if these users do not have the rights to access the release records.
