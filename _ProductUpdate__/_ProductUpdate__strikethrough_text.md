# Strikethrough Text

The Strikethrough option has been added to the [text formatting bar](https://help.xurrent.com/help/text_formatting/).  This makes it possible to present text with a horizontal line through its center.  This makes it easier to indicate to others which words should be removed from a text.  When it is used in combination with the option to give text a color, the Strikethrough option provides a means to propose edits more clearly and succinctly.

Other text formatting options that have recently been added are:

- [Insert Tables in Rich Text Fields](https://www.xurrent.com/product-updates/insert-tables-to-rich-text-fields)
- [Include Headers in Rich Text Fields](https://www.xurrent.com/product-updates/include-headers-in-rich-text-fields)
- [Add Color to Text and Tables](https://www.xurrent.com/product-updates/add-color-to-text-and-tables)
- [Copy/Paste From Excel to Rich Text Fields](https://www.xurrent.com/blog/copy-paste-from-excel-to-rich-text-fields)
