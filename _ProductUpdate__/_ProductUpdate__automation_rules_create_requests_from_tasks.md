# Automation Rules Create Requests from Tasks

It has been possible for a while now to cause [a task within a change workflow to generate a new request](https://www.xurrent.com/blog/generate-a-new-request-from-a-task) based on a request template from a different internal or external provider.  This can be configured in the ‘Request Generation’ section of a task template or task by selecting a request template in the Request template field.

What is new is that the correct request template can now be selected dynamically in the Request template field by an automation rule.

This makes it possible to build complex automation rules that select a different request template depending on, for example, the options the end user selected in the request that triggered the task’s change to be generated.
