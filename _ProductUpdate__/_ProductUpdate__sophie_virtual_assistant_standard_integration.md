# Sophie Virtual Assistant Standard Integration

A [standard integration](https://www.xurrent.com/blog/activation-of-standard-integrations) with Sophie, a virtual agent that aims to understand natural language and support users, is now available as an app. Sophie Virtual Agent can provide 24/7 first level support. She can help end users navigate a system through voice interaction, open and consult tickets, look for relevant articles, or transfer them to a human support agent. This new standard integration can be found in the ‘App Store’ section of the Settings console.

Installing the app is easy: just click on the Sophie tile and specify the URI and Tenant that are provided by Sophie’s vendor, [Stefanini](https://stefanini.com/en), to complete the setup. This will make the orange Sophie button available at the bottom of the Xurrent Self Service page. Clicking that button starts the conversation.

The full press release can be found on the [Newswire](https://www.newswire.com/news/virtual-agent-sophie-is-the-latest-integration-available-from-the-4me-21603226)website.
