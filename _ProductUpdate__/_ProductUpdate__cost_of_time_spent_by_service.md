# Cost of Time Spent by Service

An important financial management report has been added.  It is called ‘Cost of Time Spent by Service’.  This report shows how much a service provider is paying per service for the time its people spend working on these services.  The services are sorted so that the ones that cost the service provider the most are listed on top.

Using the ‘Type’ filter, it is possible to see how much time was spent on requests, versus change tasks, versus project tasks.  The ‘Request category’ filter makes it possible to see how much money has been wasted on incidents.  Adding the ‘Customer’ filter to this makes it possible to see how much can be saved by reducing the number of incidents for a specific customer.  But there are many more interesting ways to break down the data in this report.

Because financial information is considered sensitive in many organizations, this report is [disabled by default](https://www.xurrent.com/product-updates/disabling-reports).
