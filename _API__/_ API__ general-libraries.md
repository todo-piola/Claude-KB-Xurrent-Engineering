# Libraries

Please find the libraries for accessing the Xurrent API below.

If there are no libraries in your favorite language and you are willing to contribute to the Xurrent community we’d love [to hear from you](mailto:support@xurrent.com?subject=API-Library)!

## .NET

[.NET SDK for Xurrent GraphQL (1)](https://github.com/klaasvandeweerdt/works4me-xurrent-graphql)
: A Xurrent client for accessing the Xurrent GraphQL API, Bulk API and Events API using the .NET Framework and .NET, available as a [NuGet package](https://www.nuget.org/packages/Works4me.Xurrent.GraphQL).
 Developed and maintained by Klaas Vandeweerdt / [Works4me](https://www.works4me.biz/).

[.NET SDK for Xurrent GraphQL (2)](https://github.com/xurrent/graphql-dotnet/)
: Alternative Xurrent client for accessing the Xurrent GraphQL API using the .NET Framework and .NET, available as a [NuGet package](https://www.nuget.org/packages/Xurrent.GraphQL/).

[.NET REST SDK for Xurrent](https://www.nuget.org/packages/Works4me.Xurrent.Rest)
: A Xurrent client for accessing the Xurrent REST APIs using the .NET Framework and .NET, available as a [NuGet package](https://www.nuget.org/packages/Works4me.Xurrent.Rest).
 More information on [GitHub](https://github.com/klaasvandeweerdt/works4me-xurrent-rest).
 Developed and maintained by Klaas Vandeweerdt / [Works4me](https://www.works4me.biz/).

## PowerShell

[PowerShell Module for Xurrent GraphQL](https://github.com/klaasvandeweerdt/works4me-xurrent-graphql-powershell)
: A Xurrent client for accessing the Xurrent GraphQL API, Bulk API and Events API using PowerShell, available in the [PowerShell Gallery](https://www.powershellgallery.com/packages/Works4me.Xurrent.GraphQL/).
 Developed and maintained by Klaas Vandeweerdt / [Works4me](https://www.works4me.biz/).

## Ruby

[Ruby SDK for Xurrent](https://github.com/code4me/4me-sdk-ruby)
: A Xurrent client for accessing the Xurrent REST APIs using Ruby.

[Xurrent Export Monitor](https://github.com/itrp/itrp-export-monitor)
: The Xurrent Export Monitor can be used to download, unzip and distribute Xurrent export files.
